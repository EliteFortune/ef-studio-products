# EF Studio Software Portfolio

EF Studio uses one shared runtime and one monorepo. Products are commercial modules, not separate codebases.

| Product | Status | Customer question |
|---|---|---|
| Agent Reliability | BUILD / V1 FROZEN | Did my AI coding agent actually finish the job? |
| EF Evidence | PROTOTYPE | Does the evidence actually support what AI claims? |
| Agent Context | ARCHITECTURE ONLY | Is the agent getting the right context? |
| Agent Memory | DEFERRED / Context capability | What verified experience deserves to become memory? |
| Agent Control | PARKED | Should this agent action be allowed? |
| Outcome Router | DATA ONLY | Which agent/model produces the best verified outcome? |

## Build gate
No product moves to BUILD until the prior product has customer evidence or the founder explicitly overrides the gate.
