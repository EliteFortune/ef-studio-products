# V1 Non-Goals

A feature does not enter V1 unless it materially improves the answer to: **Did the AI coding agent actually finish the job?**

Excluded: memory, context selection, model routing, agent marketplace, generic observability, browser extension, cloud tenancy, organization accounts, SSO, autonomous production mutation, custom model training, managed AI inference, 24x7 support, bespoke customer forks, enterprise governance.
