# Agent Reliability V1 — Frozen Scope

## One job
Independently verify whether an AI coding agent actually completed the requested work.

## Inputs
- mission/objective
- explicit acceptance criteria
- local Git repository state
- configurable test/custom-command results
- GitHub PR/check/merge evidence
- optional HTTP/API verification

## Outputs
- VERIFIED
- FAILED
- INCOMPLETE
- UNKNOWN
- criterion-level evidence report

## Customer surfaces
- background EF runtime
- lightweight desktop console
- system tray notification
- CLI
- GitHub check/status integration where configured

## Support model
- self-service by design
- 30-day installation/activation assistance only
- built-in diagnostics and deterministic recovery
- 12-month update eligibility

## Explicit non-goals
- deep Claude/Codex/Cursor dependency
- memory platform
- context orchestration
- model routing
- cloud sync/account system
- autonomous code repair
- browser extension
- team collaboration
- enterprise RBAC/SSO
- hosted inference
