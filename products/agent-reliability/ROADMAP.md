# Agent Reliability Roadmap

## V1 — Independent completion verification
Frozen scope in `V1-SCOPE.md`.

## V1.x candidates
Only from customer evidence:
- richer deployment verification adapters
- improved mission/acceptance-criterion creation
- additional Git providers
- repair-context package generation

## V2 candidate
Loop protection only if live-agent failure loops are a demonstrated customer problem.

## Later
Context, memory, routing and runtime policy remain separate portfolio capabilities and do not automatically enter Agent Reliability.
