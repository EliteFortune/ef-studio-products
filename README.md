# EF Studio Products

Canonical monorepo for EliteFortune Studio sellable software products.

## Portfolio state
- **Agent Reliability** — BUILD / V1 FROZEN
- **EF Evidence** — PROTOTYPE ONLY
- **Agent Context** — ARCHITECTURE ONLY
- **Agent Control** — PARKED
- **Outcome Router** — DATA COLLECTION ONLY

## V1 product
**EliteFortune Agent Reliability** independently verifies whether an AI coding agent actually completed the requested work.

Core principle: deterministic evidence first; AI judgment only when deterministic evidence cannot answer the criterion.

## Monorepo layout
- `products/` — PRDs, scope, UX, commercialization
- `apps/` — customer-facing desktop/CLI surfaces
- `packages/` — shared EF runtime capabilities
- `docs/` — portfolio, architecture, commercial policy

## V1 non-goals
No cloud account system, team workspaces, memory platform, model routing, autonomous remediation, browser extension, enterprise RBAC/SSO, managed inference, or broad agent-specific integrations.
